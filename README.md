* ⚙️ **DevTrack** - A personal backend application implementing Clean Architecture and Repository Pattern. Built with FastAPI, MySQL on Aiven, JWT Authentication, Pytest, and Alembic. Documented continuously in my Medium series.
* 🎓 **Akademik Dergi Yönetim Sistemi (ADYS)** - An 11-role academic journal management system involving multi-role UI panels, localization features, and complex API connections.
* 📚 **[Akıl Kütüphanesi (Ak-Son)](https://github.com/zozbe)** - A QR code-supported, web-based Q&A platform developed with Python FastAPI, React, and Aiven MySQL architecture (TÜBİTAK Project).

* 🎬 **[CineJury](https://github.com/zozbe)** - A structural film evaluation mobile application integrated with the TMDB API featuring an equalizer-style scoring system (React Native / Expo).
