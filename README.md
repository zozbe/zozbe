### 🚀 Featured Projects

* ⚙️ **DevTrack**
  A backend task management API built with FastAPI and Clean Architecture. I use this project to practice and improve my backend development skills. I also share the development process and what I learn in my DevTrack Medium series.
  * **Tech:** FastAPI, Clean Architecture, Repository Pattern, Dependency Injection, JWT Authentication, MySQL, Alembic, Pytest, Docker, GitHub Actions.

* 🎓 **Akademik Dergi Yönetim Sistemi (ADYS)**
  An academic journal management system developed during my industry training experience. The system has 11 different user roles, role-based panels, localization features, and API integrations.
  * **Focus:** Role-based systems, API integration, Database operations, Multi-language support, Management panels.

* 📚 **[Akıl Kütüphanesi](https://github.com/zozbe)**
  A QR code-supported, web-based question and answer platform developed as a TÜBİTAK project. Users can ask questions, share answers, and interact with other students.
  * **Tech:** Python, FastAPI, React, MySQL.

* 📱 **Akıllı Kampüs Asistanı**
  A campus assistant project developed under the TÜBİTAK framework. The project focuses on providing useful campus information through a web application.
  * **Tech:** React.

* 🎬 **[CineJury](https://github.com/zozbe)**
  A mobile application for evaluating movies. The application uses the TMDB API and includes an equalizer-style scoring system for movie evaluation.
  * **Tech:** React Native, Expo, TMDB API.

* 🧠 **[DeepHAR](https://github.com/zozbe/human-activity-recognition-dl)**
  A deep learning project for human activity recognition using activity data. The project includes data preprocessing, model training, and classification.
  * **Tech:** Python, TensorFlow, Keras, Scikit-learn.

* 💧 **[Agricultural Water Footprint](https://github.com/zozbe/agricultural-water-footprint-analysis)**
  A data analysis project about agricultural water consumption. The project focuses on processing, analyzing, and visualizing agricultural water footprint data.
  * **Tech:** Python, Pandas, Data Visualization.
